📦 Alugai - Startup de Economia Compartilhada

    Status do Projeto: Projeto estático para visualização no Portfolio

    Interface: HTML5 & CSS3

    Objetivo: Facilitar o aluguel de ferramentas e itens domésticos entre pessoas.

📋 Sobre o Projeto

O Alugai é uma plataforma focada em economia compartilhada. A ideia é permitir que usuários anunciem itens que possuem em casa (como ferramentas de marcenaria, utensílios de cozinha ou equipamentos de informática) para locação, gerando renda extra para quem empresta e economia para quem aluga.

Este repositório contém a interface completa do fluxo do usuário, validando a experiência de navegação (UX) e a arquitetura da informação.
🛠️ Funcionalidades Implementadas

    Landing Page: Apresentação da plataforma com categorias em destaque.

    Fluxo de Autenticação: Telas de Login e Cadastro de novos usuários.

    Navegação por Categorias: Páginas específicas para Cozinha, Informática e Marcenaria.

    Dashboard do Usuário: Painel de controle para gerenciar itens e perfil.

    Cadastro de Itens: Formulário estruturado para inclusão de novos produtos para aluguel.

💻 Tecnologias Utilizadas

    HTML5: Estruturação semântica das páginas.

    CSS3: Estilização moderna com foco em responsividade e layout limpo.

    Design: Foco em usabilidade e facilidade de conversão.

📂 Estrutura de Arquivos

    index.html: Página principal.

    login.html / register.html: Gestão de acesso.

    dashboard.html: Painel principal após o login.

    cadastro_item.html: Fluxo de inserção de produtos.

    informatica.html, cozinha.html, marcenaria.html: Listagem de nichos.
